# battle-arena-server

팀원 이름
-전누리, 이시은, 안정현 


배틀 아레나

장르: 실시간대전-캐주얼
인원: 한 방에 2명
시간: 한 판 90초
규칙: 아이템(점수)들을 모아서 많이 모은 사람이 승리
조작: 방향키 이동만, wasd



게임에서 벌어지는 일			서버가 해야 할 일

게임을 켰다						로그인이 필요 -> 튜토리얼 -> 빠른 게임참가, 사설 게임 만들기 		

친구랑 같이 하고 싶다			방 만들기 -> 초대 코드 생성 후 로비창  

캐릭터를 움직였다				wasd, 방향키로 8방향 움직임 -> shitf(달리기), space(점프), wasd에 가까운 키(Q, R, E)에 일회성 아이템 사용    

아이템을 먹었다					일회성 아이템을 먹었을 때 이 아이템이 제한된 시간을 가짐(5초) -> 일회성 아이템을 사용하면 점수가 줄고, 사용하지 않으면 점수가 늘어난다 		

게임이 끝났다					결과가 화면이 나타남 -> 이 사람과 다시 게임을 할 것 인가, 나갈 것인가  
	
다시  접속했다					1. (게임 내에서 종료했을 때) 기존에 들어간 서버의 다른 서버로 매칭이 됨 
								2. (게임 자체를 종료했을 때) 원래의 화면이 나온다 -> 장기간 앱을 접속하지 않았으면 다시 로그인이 필요
